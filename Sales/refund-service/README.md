# Refund Service 🎮

Microservicio independiente del dominio de ventas para la **gestión de devoluciones y reembolsos** en una tienda de videojuegos.

## 🚀 Tecnologías
- Node.js
- Express
- Sequelize
- MySQL
- Docker
